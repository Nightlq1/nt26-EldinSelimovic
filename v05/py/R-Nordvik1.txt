==================================================
7. STP ROOT PRIMARY OCH SECONDARY
==================================================

SW-Nordvik-1 – Root Primary:

enable
configure terminal
spanning-tree vlan 10,20,30,99 root primary
end

show spanning-tree vlan 10

SW-Nordvik-2 – Root Secondary:

enable
configure terminal
spanning-tree vlan 10,20,30,99 root secondary
end

show spanning-tree vlan 10

Slutresultat:

SW-Nordvik-1 = Root Primary
SW-Nordvik-2 = Root Secondary
SW-Nordvik-3 = vanlig STP-switch

STP-begrepp:

Root = Root Port
Desg = Designated Port
Altn = Alternate Port
FWD = Forwarding
BLK = Blocking


==================================================
8. ROUTER-ON-A-STICK – R-NORDVIK-1
==================================================

enable
configure terminal

interface gi0/0
no ip address
no shutdown

interface gi0/0.10
encapsulation dot1Q 10
ip address 192.168.1.1 255.255.255.192

interface gi0/0.20
encapsulation dot1Q 20
ip address 192.168.1.65 255.255.255.192

interface gi0/0.30
encapsulation dot1Q 30
ip address 192.168.1.129 255.255.255.192

interface gi0/0.99
encapsulation dot1Q 99
ip address 192.168.1.193 255.255.255.192

end

10. DHCP – R-NORDVIK-1
==================================================

VLAN 10 KONTOR:

configure terminal
ip dhcp excluded-address 192.168.1.1 192.168.1.19
ip dhcp pool KONTOR
network 192.168.1.0 255.255.255.192
default-router 192.168.1.1
dns-server 192.168.1.1
end

VLAN 20 EKONOMI:

configure terminal
ip dhcp excluded-address 192.168.1.65 192.168.1.79
ip dhcp pool EKONOMI
network 192.168.1.64 255.255.255.192
default-router 192.168.1.65
dns-server 192.168.1.65
end

VLAN 30 GAST:

configure terminal
ip dhcp excluded-address 192.168.1.129 192.168.1.139
ip dhcp pool GAST
network 192.168.1.128 255.255.255.192
default-router 192.168.1.129
dns-server 192.168.1.129
end

Sätt sedan klienterna i VLAN 10, 20 och 30 på DHCP.

15. KONTROLL OCH FELSÖKNING
==================================================

På routrar:

show ip interface brief

show running-config
show ip dhcp binding

På switchar:

show vlan brief
show interfaces trunk
show spanning-tree
show spanning-tree vlan 10
show running-config

Pingtester:

ping 10.0.0.2
ping 192.168.2.10
ping 203.0.113.1

På PC:

tracert 192.168.2.10


==================================================
16. STP FAILOVER-TEST
==================================================

På SW-Nordvik-2:

enable
configure terminal
interface gi0/1
shutdown
end

Kontrollera:

show spanning-tree
show spanning-tree vlan 10

När Gi0/1 är nere ska den alternativa vägen kunna ta över:

SW-Nordvik-2 -> SW-Nordvik-3 -> SW-Nordvik-1

Återställ länken:

configure terminal
interface gi0/1
no shutdown
end

Kontrollera igen:

show spanning-tree vlan 10
